Small counters, kept on this computer.

A display is counted when a sprite becomes visible, not on every animation frame. Only visible desktop pet time is measured; hidden, minimized, suspended and studio preview time are excluded. Two visible companions accumulate time separately.

Time share uses each companion’s own recorded time, so Claude and ChatGPT each have their own 100%. Blink sprites are included and labeled. “All bundled artwork” also shows originals and other sprites outside the current rotation.

Only sprite identifiers and totals are saved locally. These counters do not change pose selection.

Installing Aipet does not register these hooks. Review and merge this configuration separately; Aipet never edits your AI settings.

  1. Keep Aipet in its final installation folder. Use the generated example below.
  2. Merge the example’s hooks entries into your configuration, preserving unrelated hooks. Replace older Aipet entries when upgrading.

The default bridge ignores hook input and writes fixed activity states. Conversation text, credentials and source files are never read by that bridge.

A narrow little world
The interface is sandboxed. Its local inbox accepts only a strict metadata schema. It cannot browse your files or run commands.
